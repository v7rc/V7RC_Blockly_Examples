# 點選人物跟拍雲台 v7

匯入 [person-follow-camera-tap-select-v7.xml](person-follow-camera-tap-select-v7.xml)，在支援畫布觸控與同步設定 Tracker 目標的 iOS V7RC App JSCore Blockly 模式執行。

## 使用方式

1. 連接一般定位伺服機雲台。CH1 控制左右，CH2 控制上下，兩者從 1500 開始。CH3／CH4 固定輸出 1500。
2. 在物件偵測啟用積木選擇實際模型，人物原始標籤須為「人」。XML 的模型欄位預設為待選狀態。
3. 啟動後會開啟相機與偵測，並選最大且信心度至少 0.55 的人物建立 Tracker 0。
4. 點擊綠色人物框內的位置可更換對象。下一次偵測結果會確認點擊是否命中人物，重疊時選較小框。原生 Tracker 成功接受新目標後才切換。

人物偵測框為綠色，目前追蹤目標以粗紅框和「追蹤目標 0」標籤顯示。左上方顯示 CH1／CH2 命令值、偵測回呼次數、物件數與鎖定狀態。

## 調整與限制

- SRT 約每 40 ms 重送一次，約 25 次／秒。
- pan_direction 和 tilt_direction 預設 1，轉向相反時改為 -1。
- 伺服機預設範圍 1100–1900，每次最多改變 8，請先確認機械行程。
- 畫面中心左右、上下各 5% 是死區。
- 一般自動選人使用 0.55 信心度門檻。手動點選可選任何有效的「人」框。
- 點擊空白或其他類別不換人。點擊請求約一秒未處理就失效。
- Tracker 約一秒未回傳有效位置時，停止調整並重新選人。SRT 持續重送保持角度。
- 使用 App 原有 OpenCV Tracker，遮擋或多人交錯仍可能漂移。

已驗證 XML 匯入、匯出及 JavaScript 生成，並模擬測試人物過濾、點選換人、空白忽略、重疊框、點擊逾時、位置限制與 SRT 重送。實機觸控及追蹤效果仍需在目標裝置驗證。
